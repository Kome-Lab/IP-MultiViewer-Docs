# 画面レイアウト

複数の映像を見やすく並べるための設定です。最初は少ない映像で配置を作り、あとから増やすと調整しやすくなります。

## 基本の考え方

- よく見る映像を大きくします。
- 監視だけでよい映像は小さくします。
- 名前が似ている映像は表示名を分かりやすくします。
- 音声を確認する映像は、見つけやすい位置に置きます。

## 設定手順

1. 映像を 2 つから 4 つ程度追加します。
2. レイアウト画面を開きます。
3. 映像の位置と大きさを調整します。
4. 表示名が読めるか確認します。
5. アプリのウィンドウサイズを変えて、崩れないか確認します。
6. 問題がなければ保存します。

## コツ

- いきなり大量の映像を並べないでください。
- 長時間見る画面では、重要な映像を左上や中央に置くと確認しやすくなります。
- トラブル時にすぐ探せるよう、表示名は場所や用途が分かる名前にします。
