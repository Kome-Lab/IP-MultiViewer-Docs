# アラート設定

映像の停止や音声の異常などに気づきやすくするための設定です。最初は通知が多くなりすぎないよう、ゆるめの条件から始めます。

## よく使う条件

- 映像が止まった
- 映像が一定時間表示されない
- 黒味フレームを検知した
- 音声が一定時間無音になった
- 接続が何度も失敗した

## 設定手順

1. アラート設定を開きます。
2. 対象にする映像を選びます。
3. 検知したい条件を選びます。
4. 黒味は輝度と暗いpixel割合、freezeや無音は継続秒数を決めます。
5. 通知先を選びます。
6. テスト通知を送ります。
7. 実際の映像でしばらく様子を見ます。

## 調整のコツ

- 短すぎる秒数にすると通知が多くなります。
- ネットワークが不安定な場所では、少し長めにします。
- 黒味は初回検知で通知するため、暗い映像ではBlack luma、Dark pixel luma、Dark pixel ratioを調整します。
- 本当に確認したい映像だけ通知対象にすると運用しやすくなります。
- 通知が多すぎる場合は、まず条件をゆるめてください。
