# タイルとウィンドウ

IP MultiViewer のメイン画面は、映像を見るための画面です。設定や alert 履歴は別ウィンドウで開き、監視画面を邪魔しない構成にします。

## タイルで見るもの

- 短い stream 名
- 状態 badge
- alert overlay
- 必要な場合の音声状態

映像面積を優先するため、常に大量の説明文を表示しない設計にします。

## 割り当て手順

1. 映像ソースを登録します。
2. レイアウト画面を開きます。
3. タイルを選びます。
4. `Assign` または `Change` で stream を割り当てます。
5. 重要な映像を大きいタイルへ置きます。
6. 保存して、再起動後も残るか確認します。

## standby表示

再生を開始していないタイルは `OK` ではなく、standby や playback stopped として扱います。未再生の状態を正常な映像として誤認しないためです。

## 見やすさのコツ

- 最重要映像は左上か中央へ置きます。
- 音声確認用の映像は見つけやすい位置へ置きます。
- alert が出やすい映像は大きくしすぎず、通知と併用します。
- 画面共有前に URL や認証情報が写っていないか確認します。
