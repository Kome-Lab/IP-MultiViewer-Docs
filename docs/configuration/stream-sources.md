# 映像ソース設定

映像ソースは IP MultiViewer の基本です。URL、認証、音声、表示名を正しく設定すると、日常確認とアラート対応がしやすくなります。

## 入力する項目

| 項目 | 説明 |
| --- | --- |
| Name | 場所や用途が分かる名前 |
| Input URL | RTSP、SRT、RTMP、HLS などの映像 URL |
| Protocol | `rtsp`、`srt`、`rtmp`、`rtmps`、`hls`、`udp_mpegts`、`rtp` など |
| Group | 拠点、部屋、用途などの分類 |
| Tags | 検索や整理用の短いラベル |
| Alert Profile | 映像ごとの検知条件 |
| Enabled | Start時に再生対象にするか |
| Analysis | 黒画面、フリーズ、低FPSなどの映像解析 |
| Audio monitor | 無音やクリッピングなどの音声監視 |
| Mute alert sound | この映像だけalert音を止める |

## 名前の付け方

- `入口カメラ`
- `配信PC 1`
- `会場全景`
- `音声確認用`

URL を表示名に入れないでください。認証情報が含まれる場合があります。

## 追加後の確認

1. 映像が表示されることを確認します。
2. 30 秒程度止まらないか見ます。
3. 音声が必要な場合は音量を確認します。
4. アプリを再起動して設定が残るか確認します。
5. 必要に応じてアラート profile を割り当てます。
6. メイン画面の現在のLayoutに割り当てます。

## 複数追加するとき

一度に大量に追加せず、数個ずつ確認してください。問題が起きたとき、どの URL や認証情報が原因か切り分けやすくなります。

## Settings画面での操作

詳しい画面操作は [Settings画面の使い方](/app/settings-window) を確認してください。映像を追加したら、`Apply Stream`、必要に応じて `Save`、メイン画面で `Start` の順に確認します。
