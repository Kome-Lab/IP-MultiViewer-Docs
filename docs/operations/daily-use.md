# 日常の見方

IP MultiViewer を日常的に使うときの基本的な確認手順です。画面を開いたら、まず映像が見えるか、音が必要な映像で音が出ているかを確認します。

## 起動したら確認すること

1. すべての映像が表示されているか確認します。
2. 黒画面や停止している映像がないか確認します。
3. 音声が必要な映像で音が出ているか確認します。
4. レイアウトが見やすい状態になっているか確認します。
5. アラートが出ている場合は、対象の映像を開いて確認します。
6. Playback summary の errors が増えていないか確認します。
7. Server sync を使う場合は、Mode表示と同期状態を確認します。

## 見やすくするコツ

- よく見る映像を大きくします。
- 異常に気づきたい映像は目立つ位置に置きます。
- 表示名は場所や用途が分かる名前にします。
- 通知が多い場合は、アラート条件を少しゆるめます。

## 異常が出たとき

映像が止まった場合は、まずネットワークと映像 URL を確認します。通知だけが届かない場合は、[通知の問題](/troubleshooting/webhooks) を確認してください。

メイン画面のボタン、タイル、alert overlay の詳しい見方は [メイン画面の使い方](/app/main-window) を確認してください。
