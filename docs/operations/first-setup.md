# 最初の設定

アプリを初めて開いたあと、最初に確認する設定です。まずは 1 つの映像を安定して表示できる状態を目指します。

## 進め方

1. アプリを起動します。
2. 表示名や保存先など、基本設定を確認します。
3. [Settings画面の使い方](/app/settings-window) を見ながら、Streamsを確認します。
4. [最初の映像を追加する](/operations/add-first-stream) に進みます。
5. 1 つの映像で再生を確認します。
6. 問題がなければ、必要な数だけ映像を追加します。
7. [画面レイアウト](/configuration/layouts) で見やすい配置にします。
8. 必要に応じて [アラート設定](/configuration/alert-profiles) と [通知先](/configuration/notification-channels) を設定します。

## 確認ポイント

- 映像 URL を間違えていない
- 認証情報が必要な映像では正しい値を入れている
- ネットワークがカメラや配信元に届いている
- 設定保存後にアプリを再起動しても残っている

## 最初に決める設定

- 画面に表示する名前の付け方
- 映像を並べる順番
- 音声を確認する映像
- 通知を出す条件
- サーバー同期を使うかどうか

最初から全部を細かく作り込む必要はありません。まず 1 つの映像で確認し、次に 4 つ程度まで増やして、最後に通知や同期を追加します。

## サーバー同期について

最初は使わなくても問題ありません。複数端末で同じ設定を使いたい場合や、履歴を共有したい場合に追加してください。
