# 通知を受けたとき

アラートや通知が届いたときに、どの順番で確認するかをまとめます。

## まず確認すること

1. 通知に書かれた映像名を確認します。
2. IP MultiViewer で対象の映像を開きます。
3. 黒画面、停止、無音など、通知内容と同じ状態か確認します。
4. 他の映像も同時に止まっていないか確認します。
5. 一時的な揺れであれば、数十秒待って復旧するか確認します。

## 原因を切り分ける

- 1 つの映像だけ止まる場合: カメラ、URL、認証情報を確認します。
- 複数の映像が止まる場合: ネットワークや VPN を確認します。
- 通知だけ届かない場合: Webhook URL と通知先を確認します。
- 音声だけ問題がある場合: 音量、ミュート、入力元を確認します。

## 対応後

復旧したら、同じ通知が何度も出ていないか確認します。頻繁に通知が出る場合は、[アラート設定](/configuration/alert-profiles) で条件を調整してください。
