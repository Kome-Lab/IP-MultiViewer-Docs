# 最初の映像を追加する

最初に 1 つの映像を追加して、再生できることを確認します。複数の映像を追加する前に、1 つずつ確実に確認してください。

## 手順

1. アプリを起動します。
2. Settings を開きます。
3. 表示名を入れます。
4. 映像 URL を入れます。
5. Protocol、Group、Tags、Alert Profileを確認します。
6. 音声が必要な映像では Audio monitor を有効にします。
7. `Apply Stream` を押します。
8. 必要に応じて `Save` を押します。
9. メイン画面でStartし、映像と音声を確認します。
10. 問題がなければ、同じ手順で次の映像を追加します。

## 入力する内容

| 項目 | 入れる内容 |
| --- | --- |
| 表示名 | 場所や用途が分かる名前 |
| 映像 URL | カメラや配信元の URL |
| 認証情報 | 必要な場合だけ入力 |
| 音声 | 音を確認したい映像だけ有効化 |
| アラート | 最初は無効またはゆるめに設定 |

## 確認ポイント

- 映像が表示される
- 音声が必要な場合は音が出る
- 数十秒待っても映像が止まらない
- 表示名でどの映像か分かる
- 認証情報が画面やログにそのまま出ていない

## うまく表示されないとき

- URL の入力ミスを確認します。
- 同じ URL をブラウザや別プレイヤーで開けるか確認します。
- 社内ネットワークや VPN が必要な映像では、接続先を確認します。
- 認証付き URL は、スクリーンショットに写さないようにしてください。

Settings の項目説明は [Settings画面の使い方](/app/settings-window)、再生条件は [再生と検知機能](/app/playback-and-analysis) を確認してください。
