# 通知の問題

アラートは出ているのに通知が届かない、または通知が多すぎる場合の確認手順です。

## 届かないとき

1. 通知先設定でテスト通知を送ります。
2. Webhook URL が正しいか確認します。
3. 通知先サービス側で Webhook が無効になっていないか確認します。
4. Windows PC から外部へ通信できるか確認します。
5. アラート設定で通知先が選ばれているか確認します。

## 多すぎるとき

1. どの映像から通知が出ているか確認します。
2. 検知までの秒数を長くします。
3. 重要度の低い映像は通知対象から外します。
4. 復旧通知が必要か見直します。

## 注意

Webhook URL は公開しないでください。漏れた可能性がある場合は [Webhookの扱い](/security/webhook-secrets) を確認してください。
