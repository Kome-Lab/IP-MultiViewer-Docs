# 音声の問題

映像は出ているのに音が出ない、音が小さい、無音アラートが多い場合の確認手順です。

## 確認する順番

1. その映像に音声が含まれているか確認します。
2. アプリ内でミュートになっていないか確認します。
3. Windows の音量ミキサーを確認します。
4. 出力先デバイスが正しいか確認します。
5. 別のプレイヤーで同じ映像を開き、音が出るか確認します。
6. 無音アラートの秒数が短すぎないか確認します。

## 調整のコツ

- 音声が不要な映像では、無音アラートを使わないようにします。
- 一時的な無音がある映像では、検知までの秒数を長めにします。
- 大事な音声だけ通知対象にすると、通知疲れを減らせます。
