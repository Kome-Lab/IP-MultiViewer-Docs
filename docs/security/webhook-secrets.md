# Webhookの扱い

通知用 Webhook URL は、知っている人が通知先へ投稿できる場合があります。パスワードに近い情報として扱ってください。

## 公開しない場所

- GitHub
- issue やチャット
- スクリーンショット
- デモ動画
- 誰でも見られるログ

## 漏れた可能性があるとき

1. 通知先サービスで古い Webhook URL を無効化します。
2. 新しい Webhook URL を作ります。
3. IP MultiViewer の通知先設定を更新します。
4. テスト通知を送ります。
5. 古い URL がドキュメントやログに残っていないか確認します。

通知設定の通常手順は [通知先](/configuration/notification-channels) を確認してください。
