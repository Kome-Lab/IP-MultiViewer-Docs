# 安全に公開する

IP MultiViewer を安全に使うための基本です。通常は Windows アプリをローカルで使うため、外部公開するものは多くありません。サーバー同期や通知を使う場合だけ、公開範囲を意識してください。

## 守ること

- カメラURL、ユーザー名、パスワードを GitHub や公開資料に書かない
- 通知用 Webhook URL を公開しない
- 共有PCでは設定ファイルの扱いに注意する
- サーバー同期を使う場合は HTTPS を使う
- 不要なポートを外部公開しない

## サーバー同期を使う場合

1. 同期サーバーは HTTPS で使います。
2. 必要な端末だけがアクセスできるようにします。
3. 使わないアカウントや古い端末を残さないようにします。
4. 映像 URL や Webhook URL を含む設定の扱いを決めておきます。
5. 設定を共有する前に、不要な秘密情報が入っていないか確認します。

## 画面共有やスクリーンショットの注意

映像URL、通知URL、認証情報が画面に出ていないか確認してから共有してください。

## 公開してよい情報

- インストール方法
- 基本的な使い方
- 対応している映像方式
- placeholder だけの設定例

実際のカメラ URL、ユーザー名、パスワード、Webhook URL は公開しないでください。
