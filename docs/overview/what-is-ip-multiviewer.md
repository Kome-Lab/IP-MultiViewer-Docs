# IP MultiViewerとは

IP MultiViewer は、複数の映像を一画面で見守るための Windows アプリです。

監視カメラ、配信映像、ネットワークカメラなどを並べて表示し、異常がないか確認しやすくします。

## できること

- 複数の映像を一画面に並べる
- 表示名を付けて見分けやすくする
- レイアウトを調整する
- 黒画面、停止、無音などに気づきやすくする
- 必要に応じて通知先へ知らせる
- 複数端末で同じ設定を使う

## 向いている使い方

- 複数の映像を同時に確認したい
- 映像が止まったらすぐ気づきたい
- 黒画面や無音を見逃したくない
- 通知やアラート音で知らせたい

## 最初の使い方

1. Windows アプリを入れます。
2. まず 1 つの映像を追加します。
3. 数十秒再生して、映像と音声を確認します。
4. 必要な映像を増やします。
5. レイアウトとアラートを調整します。

## まずは単体利用でよい

最初からサーバーを用意する必要はありません。まず Windows アプリを入れて、映像を追加し、必要に応じてアラートを設定してください。
