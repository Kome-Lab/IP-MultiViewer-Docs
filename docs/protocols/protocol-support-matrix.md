# 対応プロトコル

映像を受け取る方式についてのページです。

## まず知っておくこと

カメラや配信機材によって、使えるURL形式が違います。迷ったら、機材の管理画面や説明書で RTSP、SRT、HLS などの配信URLを確認してください。

## 選び方

- 監視カメラでは RTSP がよく使われます
- 遅延を少なくしたい場合は SRT が向いています
- ブラウザや配信サービスでは HLS が使われることがあります

## 入力前に確認すること

1. 映像元の管理画面で配信 URL を確認します。
2. ユーザー名やパスワードが必要か確認します。
3. Windows PC から同じネットワークへ接続できるか確認します。
4. 別のプレイヤーで再生できるか確認します。
5. 音声が必要な場合は、映像元が音声を出しているか確認します。

## 方式ごとの目安

| 方式 | よくある用途 | 確認ポイント |
| --- | --- | --- |
| RTSP | 監視カメラ、ネットワークカメラ | 認証情報とネットワーク経路 |
| SRT | 低遅延の配信 | port と接続モード |
| HLS | 配信サービス、Web向け映像 | URL の有効期限と遅延 |

## 困ったとき

別のプレイヤーで同じURLが再生できるか確認してください。再生できない場合は、IP MultiViewer ではなくカメラ、配信元、ネットワーク側の問題である可能性があります。
