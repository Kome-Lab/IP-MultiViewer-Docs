# Windowsアプリ

IP MultiViewer を Windows で使い始めるための手順です。最初はサーバー同期や通知を入れず、映像が安定して見えるところまで確認します。

## インストール前に確認すること

- Windows 10 または Windows 11 の端末
- カメラや配信機器にアクセスできるネットワーク
- 追加したい映像の URL
- 認証が必要な場合はユーザー名とパスワード
- 通知を使う場合は Webhook URL

## 手順

1. GitHub Release から Windows 版をダウンロードします。
2. zip の場合は任意のフォルダーに展開します。
3. `IPMultiViewer-<Version>-Desktop.exe` を起動します。
4. Windows の確認画面が出た場合は、発行元と保存場所を確認してから実行します。
5. 最初の画面が開いたら、[最初の設定](/operations/first-setup) に進みます。

## 置き場所の例

- 個人利用: `Downloads` ではなく、自分で管理しやすいフォルダー
- 業務端末: 管理者が決めたアプリ用フォルダー
- 設定バックアップ: 端末の利用ルールに合わせた保存場所

zip を展開した場所をあとから移動すると、ショートカットや設定の参照先を見直す必要がある場合があります。

## 起動後に確認すること

- 映像が表示される
- 音声が必要な場合は音が出る
- 画面サイズを変えてもレイアウトが崩れない
- アプリを閉じて開き直しても設定が残る

## 更新するとき

1. 起動中のアプリを閉じます。
2. 新しい release をダウンロードします。
3. 既存の実行ファイルを退避します。
4. 新しい実行ファイルを配置します。
5. 起動して、映像と設定が残っているか確認します。

## サーバー同期について

最初は使わなくても問題ありません。複数端末で同じ設定を使いたい場合や、履歴を共有したい場合に追加してください。
