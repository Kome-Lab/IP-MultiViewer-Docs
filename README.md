# IP MultiViewer Docs

Public user and operator documentation for IP MultiViewer.

## Commands

```powershell
npm install
npm run docs:dev
npm run docs:check
npm run docs:build
```

`docs:check` runs the VitePress build against the public docs tree. Internal docs generation, audit, evidence, and provider verification helpers are not part of this public repository.

If Japanese text appears corrupted in Windows PowerShell output, first suspect console encoding. Verify the source bytes with a UTF-8 reader such as Node before editing the file.
